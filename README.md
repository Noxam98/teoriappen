# Teoriprøven B — тренажёр теоретического экзамена на права в Норвегии

Это тренажёр норвежского теоретического экзамена на водительские права, класс B. Вопросы на норвежском (bokmål), как на настоящем экзамене. Непонятное слово переводится на русский кнопкой **«Перевод»**.

- **Экзамен** как настоящий: 45 вопросов, 90 минут, сдано при ошибках не больше 7. Таймер, отметки «Merk», обзор всех вопросов, в конце разбор ошибок и результаты по темам. Таймер идёт, только пока приложение на экране: если переключиться на другую вкладку, свернуть браузер или закрыть приложение, он встаёт на паузу и продолжает с того же места, когда вы вернётесь.
- **Когда показывать ответ** выбирается на главной или в настройках ⚙. По умолчанию ответ показывается **сразу после вопроса**: он фиксируется, видны правильный вариант, объяснение и счётчик ошибок «×3/7». Второй вариант — **после всех вопросов**, как на настоящем экзамене: ответы можно менять, а разбор появляется в конце. Режим действует и в экзамене, и в тренировке.
- **Теория.** По главе на каждую из 17 тем экзамена: правила простым норвежским языком, под каждым абзацем перевод на русский; переключатель «Оба языка / Norsk / Русский» оставляет только норвежский текст или только русский. В главах есть знаки и перекрёстки, рамки «Запомните» и «Ловушка на экзамене», важные цифры. Любое слово переводится кнопкой «Перевод». Прочитанные главы отмечаются, а из главы можно сразу перейти к вопросам по её теме. После тренировки и экзамена у каждой темы в результатах есть кнопка теории.
- **Тренировка по темам** с объяснениями на норвежском и, по кнопке, на русском. В конце показывается результат и разбор ошибок.
- **Работа над ошибками.** Здесь собираются вопросы, на которые в последний раз был дан неверный ответ.
- **Автоперевод браузера отключён** (`translate="no"`): норвежский текст должен оставаться норвежским, а машинный перевод искажает кнопки экзамена. Для перевода есть своя кнопка.
- **Перевод слов.** Кнопка **«Перевод»** (иконка Å → Я) включается в панели сверху. Пока режим включён, все переводимые слова подчёркнуты, а остальное бледнеет и не нажимается: случайно ответить на вопрос нельзя. Можно нажать на слово или провести по нескольким словам. Выбранное слово подсветится и появится перевод: словарная форма, грамматика и значение. Работает и наоборот: выделите текст мышкой и нажмите «Перевод».
- **Мой словарь.** Слова, сохранённые из перевода, можно учить карточками. Если в системе есть норвежский голос, можно послушать произношение.
- **Перевод в контексте через Claude.** Работает, только когда страница открыта как артефакт на claude.ai, и ничего не стоит, пока ею не пользуются. Локально кнопки нет, остаётся встроенный словарь.

Интерфейс рассчитан в первую очередь на телефон:
- главные кнопки внизу экрана, под большим пальцем;
- окна (обзор вопросов, настройки, перевод) выезжают снизу и закрываются смахиванием вниз, крестиком или Esc;
- области нажатия не меньше 44 px (рекомендации Apple и Google, WCAG 2.2);
- есть светлая и тёмная тема, размер текста вопросов настраивается;
- на Android после ответа бывает короткая вибрация.

**Звуки** синтезируются в браузере (Web Audio, `src/lib/sound.ts`): файлов нет, всё работает офлайн. В настройках есть выключатель, громкость (тихо / обычно / громко) и кнопка «Проверить звук». На iPhone звуки слушаются беззвучного режима и не прерывают музыку.

| Когда | Звук |
|---|---|
| правильный / неправильный ответ | двойной звон / мягкий «бонк» |
| 5, 10, 15… правильных подряд | переливчатый перезвон, в тренировке значок «серия N» |
| 8-я ошибка в экзамене (уже не сдать) | короткое «ой-ой» |
| начало экзамена / тренировки | «светофорный» отсчёт, как на старте гонки / «бип-бип» |
| экзамен сдан / не сдан | штамп и фанфары / штамп и мягкое «уа-уа» |
| конец тренировки | перезвон, если верно от 80 %, иначе спокойный аккорд |
| осталось 5 минут / время вышло | колокольчик / три нисходящих сигнала |
| перевод слова, слово сохранено, переворот карточки, отметка «Merk» | тихие перелив, «блип», «вжух», щелчок |

В режиме «после всех вопросов» выбор ответа беззвучен, чтобы звук не подсказывал правильность.

**Приложение на телефоне (PWA).** Сайт можно установить на главный экран: в Android через «Установить» в настройках тренажёра, в iPhone через «Поделиться» → «На экран „Домой“». После первого открытия он работает без интернета. Шрифты встроены в приложение, на сторонние серверы ничего не грузится.

**Доступность.** Проверено axe-core (WCAG 2.2 AA, 0 нарушений) и Lighthouse (телефон: производительность 99, доступность / best practices / SEO по 100). Контраст текста не ниже 4.5:1. Всё работает с клавиатуры: фокус остаётся внутри открытого окна, стрелки переключают варианты ответа. Экранные дикторы озвучивают «Верно / Неверно», норвежский текст размечен `lang="nb"` для правильного чтения и переносов. Есть ссылка «К содержимому» и уважается настройка «уменьшить движение».

В базе 337 вопросов по 17 темам и словарь на 1769 словоформ и 185 устойчивых выражений. Прогресс хранится в браузере (localStorage) на этом устройстве.

> Вопросы написаны с нуля по норвежским правилам дорожного движения (trafikkreglene, skiltforskriften). Это не официальная база Statens vegvesen: она закрыта. Правила проверены по состоянию на октябрь 2026. Если в чём-то сомневаетесь, сверяйтесь с [vegvesen.no](https://www.vegvesen.no).

## Запуск

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который покажет консоль (обычно http://localhost:5173).

### Сборка

```bash
npm run build
```

Получится папка `dist/`, её можно выложить на любой хостинг: GitHub Pages, Netlify, Vercel. Такая версия устанавливается на телефон и работает офлайн (service worker `public/sw.js`, манифест `public/manifest.webmanifest`).

```bash
npm run build:single
```

Получится `dist-single/index.html`: один файл, где всё внутри. Его можно открыть двойным щелчком, отправить по почте или скинуть на телефон. Интернет нужен только для шрифтов, без него подставятся системные.

## Как добавить вопрос

Откройте файл темы в `src/data/questions/`, например `vikeplikt.json`, и добавьте объект:

```json
{
  "id": "vik-99",
  "cat": "vikeplikt",
  "q": "Du kommer til et veikryss uten skilt. En bil kommer fra høyre. Hva gjelder?",
  "img": null,
  "a": [
    "Du har vikeplikt for bilen fra høyre",
    "Bilen fra høyre har vikeplikt for deg",
    "Den som kjører fortest, kjører først"
  ],
  "f": "Høyreregelen: i kryss uten skilt viker du for kjørende fra høyre.",
  "ru": "Правило правой руки: на перекрёстке без знаков уступаете тем, кто справа."
}
```

- **Правильный ответ всегда первый** (`a[0]`), приложение само перемешивает варианты.
- Если нужно выбрать один знак из нескольких на картинке, добавьте `"byNumber": true` и начните варианты с «Skilt 1 …», «Skilt 2 …». Знаки на картинке получат номера, а варианты не перемешиваются: вариант 1 — всегда знак 1.
- Картинка `img` может быть одной из таких:
  - `{"sign": "vikeplikt"}` — знак (все названия в `src/components/figures/signs/catalog.tsx`);
  - `{"signs": ["fart_50", "fart_80"]}` — несколько знаков;
  - `{"light": "gulblink"}` — светофор;
  - `{"road": "sperrelinje"}` — разметка;
  - `{"scene": {"type": "x", "veh": [{"id": "A", "from": "s", "go": "left", "me": true}]}}` — перекрёсток. Пешеходный переход с пешеходом задаётся как `"ped": ["n"]`, а `"pedAt": "crossing"` ставит пешехода прямо на «зебру» (по умолчанию он стоит у края тротуара).
- Новые норвежские слова добавьте в `src/data/dictionary/words.json`.

Затем проверьте:

```bash
npm run validate
```

Скрипт покажет ошибки в формате и слова, которых нет в словаре.

## Как изменить теорию

Глава темы лежит в `src/data/theory/<тема>.json`: `lead` и `leadRu` — вступление, `blocks` — содержание по порядку. Вид блока задаёт его первый ключ, у каждого норвежского текста есть русский перевод:

```json
{ "h": "Høyreregelen", "ru": "Правило правой руки" }
{ "p": "I kryss uten skilt …", "ru": "На перекрёстке без знаков …" }
{ "rule": "Ved stoppskilt skal du alltid stanse helt.", "ru": "У знака «Стоп» …" }
{ "trap": "Mange tror at …", "ru": "Многие думают, что …" }
{ "list": [["Norsk punkt", "Русский пункт"]] }
{ "fig": { "sign": "stopp" }, "no": "Stopp: stans helt.", "ru": "Стоп: полностью остановитесь." }
{ "signs": [["vikeplikt", "Vikeplikt: vik for trafikk fra begge sider", "Уступите дорогу …"]] }
{ "nums": [["50 km/t", "i tettbygd strøk", "в населённом пункте"]] }
```

`h` — подзаголовок, `p` — абзац, `rule` — рамка «Запомните», `trap` — «Ловушка на экзамене», `fig` — картинка в том же формате, что `img` у вопроса. В `signs` название знака отделяется от смысла двоеточием, и название выделяется жирным. `nums` — карточки с цифрами. Новые слова тоже добавьте в словарь, а `npm run validate` проверит и теорию.

### Лаборатория картинок

```bash
npm run lab
```

Откроется `debug.html`: на одной странице все знаки, светофоры, разметка, схемы перекрёстков из вопросов и карточки всех вопросов. Страница сама проверяет геометрию и подсвечивает проблемы красным:
- пиктограмма знака не выходит за белое (синее) поле;
- символы и надписи разметки лежат внутри своей полосы;
- машины стоят на асфальте и не наезжают друг на друга, знаки у перекрёстка стоят на обочине;
- ничего не обрезается краем картинки;
- ни одно слово в карточке вопроса не вылезает за её край. Чтобы проверить телефонную ширину, сузьте окно.

Список проблем выводится вверху страницы. Надпись «✓ no problems» значит, что всё в порядке.

## Горячие клавиши

`1`–`4` или `A`–`D` — выбрать ответ, `→`/`←` — следующий/предыдущий вопрос, `T` — режим перевода, `Esc` — закрыть перевод или выключить режим перевода.
